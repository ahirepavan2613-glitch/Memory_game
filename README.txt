MEMORY MATCH GAME
=================

A simple memory matching game made using Python and Tkinter.

FILES
-----
memory_game.py
README.txt

HOW TO RUN
----------
1. Make sure Python is installed.
2. Open the project folder in VS Code or PyCharm.
3. Run:

    python memory_game.py

HOW TO PLAY
-----------
1. Click any card.
2. Click another card.
3. If the two symbols match, they stay open.
4. If they do not match, they close again.
5. Match all 8 pairs to win.

CONCEPTS USED
-------------
- Python classes
- Tkinter GUI
- Buttons
- Lists
- Loops
- Functions
- Random module
- Event handling
